# Замена динамического функционала на вкладки со скриншотами

Задача пользователя: сохранить визуал и фон, изменить только блок функционала в копии 11housemarketing. Прямой референс и структура выбраны пользователем.

## Reference matrix / направление

- https://elevenhouse-design-preview.lysovmental.chatgpt.site/#functions: порядок девяти вкладок, выбранный календарь, описание + три шага + большой скриншот, увеличение изображения.
- Текущая 11housemarketing: заголовок Vetrino, основной Manrope, космический WebGL-фон, navy surfaces, золотые акценты, готовые авторские иконки.
- Основной вариант: постоянные вкладки сверху, ниже текст слева и скрин справа; на узком экране текст и скрин вертикально.
- Альтернативы: весь контент вертикальным списком слишком удлинит страницу; сохранение отдельного меню и возврата добавит лишний шаг. Выбрана структура, прямо запрошенная пользователем.
- Короткие описания и три шага из референса. Тарифные обещания не переносить: тарифы референса отличаются от текущей копии. Пометки об исходных/пустых экранах сохранить, где нужны.

## Изоляция и архитектура

Изменить только ProductExperience.tsx: секцию доступа оставить идентичной, функционал подключить отдельным FeatureScreenshotBrowser. Создать data-модуль featureScreenshots.ts и scoped featureScreenshotBrowser.css. Изображения сохранить в public/assets/feature-screenshots. Никаких global styles, зависимостей, Hero, JourneyLanding или остальных секций не менять.

## Motion / accessibility / performance

Без автопереключения, сценарного проигрывания, прокрутки при выборе. Только opacity 180ms при смене панели, отключённая для reduced motion. Локальные WebP 1800×1024, фиксированный aspect ratio, lazy loading. Никаких новых RAF/timers. Native dialog для увеличения: Escape, focus trap/return средствами браузера. Tabs: roving tabindex, Left/Right/Home/End, aria-selected/controls/labelledby. CSS не меняет фон страницы.
