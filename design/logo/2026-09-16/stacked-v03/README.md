# ElevenHouse — версия 03

Двухстрочное написание eleven / house сохранено.

h построена из прямой высокой стойки и точной геометрии n: внешнее плечо разделено при x=36 методом де Кастельжо, оставшаяся часть кривой сохранена без изменения. Внутреннее плечо и правая вертикальная ножка совпадают с n. Изогнутая стойка и закрученный хвост версии 02 убраны.

Новая h также применена в монограмме eh. Интервал h–o уменьшен вслед за сокращением ширины h. Цвета прежние: #010308, #F2F1EB, #E2CA79. SVG содержит замкнутые векторные контуры, без шрифтов и растров.

Предыдущие эскизы сохранены. Лендинг не изменён.
