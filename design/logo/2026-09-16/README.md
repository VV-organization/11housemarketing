# ElevenHouse — lettering study 01

Отдельный эскиз логотипа, не интегрирован в лендинг.

Источник направления: предоставленный пользователем скриншот Valence. Перенесены принципы строчного набора, высоких выносных элементов, асимметричных плеч и диагональной пластики `e`. Контуры букв нарисованы вручную кривыми Безье, без шрифта и трассировки изображения.

Палитра взята из `src/styles.css`: #010308, #F2F1EB, #E2CA79.

- `elevenhouse-ivory.svg` — светлый логотип, прозрачный фон.
- `elevenhouse-gold.svg` — золотой логотип, прозрачный фон.
- `elevenhouse-ink.svg` — тёмный логотип, прозрачный фон.
- `preview.svg` / `preview.png` — лист для просмотра.
- `draw_logo.py` — исходные контуры и сборка SVG.
- `render_preview.swift` — растровое превью тех же контуров через CoreGraphics.

SVG содержит только векторную геометрию и метаданные доступности. Каждая буква доступна как отдельный path. Написание: elevenhouse, строчными, с увеличенным интервалом между eleven и house.
